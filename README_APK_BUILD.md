# LevelUp 30 — APK-ready Android project

This project is configured as an Android Studio project.

## Build an APK
1. Install the latest Android Studio on a Windows/macOS/Linux PC.
2. Open this project folder in Android Studio.
3. Let Gradle sync and download dependencies.
4. Choose **Build > Build App Bundle(s) / APK(s) > Build APK(s)**.
5. Android Studio will show the generated APK location.
6. Copy the APK to your Android phone and install it.

## Notes
- Application ID: `com.levelup30.app`
- The app stores challenge progress locally using SharedPreferences.
- The project targets Android API 35.
- This package is intended to be built into an APK; it is not itself an installable APK.
